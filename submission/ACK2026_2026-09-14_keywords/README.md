# 키워드를 수정한 제출용 원고

2026-09-14. 이 폴더의 PDF가 현재 교체 제출용 파일이며, 같은 이름의 DOCX가 편집용 원본이다.

키워드의 ‘판단 보류’만 ‘SPICE 시뮬레이션’으로 교체했다.

> LLM, 집중소자 RF 회로, 성능 복구, 원인 진단, SPICE 시뮬레이션

기존 제출용 PDF와 DOCX는 이전 폴더에 보존했다. DOCX 패키지에서 해당 키워드 문자열 외에는 변경이 없으며,
최종 PDF도 각 페이지의 텍스트를 이전 PDF와 대조해 키워드 외 변경이 없음을 확인했다.
A4 3쪽, 제목·본문 글꼴 포함, 텍스트 추출, 표·그림·수식·문헌 배치를 확인했다.
세부 해시는 `verification.json`에 기록했다. 투고 시스템의 업로드 파일이나 키워드 입력란은 변경하지 않았다.

PDF 재현 시 `build/paper_keywords_2026-09-14/fonts.conf`를 FONTCONFIG_FILE로 지정하고
기존 documents/render_docx.py에 --emit_pdf 옵션을 사용한다. 기본 렌더 설정은 한글 글꼴을 찾지 못할 수 있다.
