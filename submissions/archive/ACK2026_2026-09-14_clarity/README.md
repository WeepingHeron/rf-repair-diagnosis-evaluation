# 기여 문장과 실험 조건 표현을 다듬은 원고

2026-09-14. 현재 교체 제출용 PDF와 편집용 DOCX는 이 폴더에 있다.

서론의 기여 문장을 동일 실행의 복구·진단 교차 평가로 명확히 하고, 5절의 기준 측정 비교 세 조건을 풀어 썼다. 키워드 SPICE 시뮬레이션은 유지했다. 두 문장 교체 외 원고 내용·수치·서식은 보존했다.

최종 PDF A4 3쪽, 글꼴 포함·Unicode 텍스트 추출·세 페이지 배치를 확인했다. PDF 전체 텍스트도 이전본에서 두 문장을 교체한 결과와 일치한다. 세부 해시는 verification.json에 있다. 기존 제출본은 이전 폴더에 보존했으며 투고 사이트는 변경하지 않았다.
