# 전체 원고를 보존한 3쪽 PDF

현재 제출용 파일은 이 폴더의 `ACK2026_KimTaehoon_RF_Circuit_Repair.pdf`다.
내용을 줄인 비교 후보는 채택하지 않았다. [글꼴 정렬본](../ACK2026_2026-09-07_fonts/README.md)의
본문·결과표 6개·그림 1개·수식 1개·참고문헌 7개를 모두 유지했다.
편집용 DOCX는 해당 폴더에 원본 그대로 남겨 두었다.

PDF는 제목·저자·초록 아래에서 첫 페이지 본문을 시작한다. 제목과 절 제목은
NanumGothic, 본문은 AppleMyungjo이며 사용한 13개 글꼴 리소스가 모두 포함되어 있다.
표 1~5는 2쪽, 표 6은 3쪽에 있고 각 표가 한 단 안에서 온전히 이어진다.
Google Docs 인쇄 미리보기에서 확인된 글꼴 대체와 표 3의 단 분할을 피하기 위해
글꼴 정렬본을 로컬에서 출력한 검토 완료 PDF를 최종 파일로 확정했다.

## 검증 범위

- A4 세로 3쪽. 세 페이지의 렌더 이미지를 모두 확인했으며 잘림·겹침 없음.
- 수식 포함 문단을 제외한 텍스트 문단 141개의 원문 일치 확인. 수식과 그림은 시각 확인.
- 한글 텍스트 추출 가능, 암호화 없음, 글꼴 리소스 13개 모두 포함 및 Unicode 매핑 존재.
- 별도 글꼴로 그려진 마이너스 기호는 단순 PDF 명령 순서 추출에서 뒤로 이동할 수 있어,
  좌표 기반 2단 추출을 함께 사용해 원문과 대조했다.
- 원본 DOCX SHA-256: `70ed75b6d207bee94aa647c0b83d9a8b5b56e3ec703695cbac92ce15ea911fa7`
- 최종 PDF SHA-256: `46f97a2a641a877b1feda3d048ec46b457670c0f5fde086d15baec05ea045874`
- 상세 검증: `verification.json`. 내보내기 재현: `scripts/export_paper_pdf.py`.

3쪽이라는 확인은 이 고정 PDF에 적용된다. 같은 DOCX를 Apple Pages에서 열면
구역 배치가 달라져 4쪽으로 표시되는 것을 직접 확인했다. Google Docs에서도 글꼴·표
배치가 바뀔 수 있으므로 최종 제출 전 비교 기준은 이 PDF로 삼는다.
이번 작업에서 논문 내용·실험 결과를 변경하거나 추가 실험을 실행하지 않았다.
