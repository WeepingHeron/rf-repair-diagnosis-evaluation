# 복구와 진단의 근거 제시를 보완한 논문

현재 검토·제출 대상은 이 폴더의 **ACK2026_KimTaehoon_RF_Circuit_Repair.docx** 한 파일이다.
제목은 「집중소자 RF 회로에서 LLM 기반 복구와 원인 진단의 분리 평가」다.
이전 `ACK2026_2026-09-06_reframed` 원고는 보존했다.

## 반영한 세 부분

1. 주 실험 48회의 복구·전체 진단 교차표를 표 3으로 추가했다. 둘 다 성공 35회, 복구만 성공 11회,
   진단만 성공 2회, 둘 다 실패 0회다. 복구만 성공한 11회는 위치 오진 3회와 위치 정답·유형 오진 8회로
   구분한다. 표 2의 46/48·37/48과 같은 실행을 사용하며 새로운 실험 분모가 아니다.
2. 그림 1을 진단 정답 대조와 SPICE 복구 판정의 두 경로로 교체했다. 주입 정답은 평가기에서만 사용하고
   LLM 입력·실패 피드백으로 흐르지 않는다. 서론·초록·결론도 이 교차 평가의 의미를 중심으로 맞췄다.
3. 기준 측정·보류 실험은 ‘진단 증거와 식별 한계의 보조 탐색’으로 명시했다. 보류 개선 수치는 본문에
   유지하고, 잔차·간격·비율만으로 전체 판정과 같았다는 한계를 함께 제시했다. 추가 기여가 없었던
   16회 재검사의 상세는 `docs/stability_extension_v1_results.md`에 보존하고 본문에서는 생략했다.

기존 결과표 5개의 내용·구조를 보존하고 이후 표 번호를 하나씩 옮겼다. 작은 교차표와 보류표가 단을
가로질러 분리되지 않도록 문단 연결 설정만 추가했다. 표를 반복하는 설명과 실험 이력은 압축하되
주요 사양·분모·비교 조건·실패 포함 원칙을 유지했다. 새 API 호출이나 시뮬레이션 실험은 수행하지 않았다.

## 재현

번들 Python으로 `scripts/update_paper_evidence.py`를 실행한 뒤 documents 스킬의 `render_docx.py`로
렌더링한다. `scripts/audit_paper_evidence.py --template <공식 양식 DOCX> --render-dir <렌더 디렉터리>`가
원본 보존·교차 수치·보조 평가·양식·페이지를 확인한다. 그림 원본은
`build/paper_evidence_update/separate_evaluation.svg`, 변경 내역은 `build/paper_evidence_update/changes.json`이다.
