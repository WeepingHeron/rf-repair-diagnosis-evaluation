# ACK 2026 초기 제출 패키지

## 실제 업로드 파일

`ACK2026_KimTaehoon_RF_Circuit_Repair.docx`

위 DOCX 한 개만 논문 파일로 업로드한다. 원고는 공식 Word 양식의 A4 2쪽이며, 추적 변경과
댓글이 없고 문서 메타데이터를 정리했다. 표 머리글과 그림 대체 설명도 포함한다.

현재 패키지에는 PDF를 넣지 않았다. ACK 2026은 Word/HWP 제출을 허용하고, 이 컴퓨터의
자동 PDF 변환기가 한글 글꼴을 누락하기 때문이다. 검증되지 않은 PDF보다 원본 DOCX를
제출하는 편이 안전하다.

## 함께 보는 파일

- `submission_form_values.md`: 투고 시스템 입력값
- `pre_submission_checklist.md`: 제출 전후 확인 사항

이 두 Markdown 파일은 제출 보조 자료이며 학회에 업로드하지 않는다.
