# 진단과 보류 기준 확장을 반영한 논문

이 폴더는 진단 확장을 추가한 이전 원고의 보존본이다.
현재 검토 대상은 [문제 정의와 주장을 보완한 원고](../ACK2026_2026-09-06_reframed/README.md)다.
기존 `2026-09-06_extended` 원고는 보존했다. 이번 작업은 문서 업데이트이며 제출 사이트 업로드는 수행하지 않았다.

## 변경 내용

- 기존 주 결과와 표 1~4, 제목·저자·그림·공진식·참고문헌을 유지했다.
- 초록에 별도 손실 모델의 수치 역추정·보류 기준 평가 결과와 합성 범위를 반영했다.
- 5절에 손실 보상 설계 비교, 진단 전용 후보 공개 비교, 고장 전 기준 측정·역추정 비교를 추가했다. 기준 측정 비교의 정상 사양 미달 설계 제외와 적격 부분집합 선택도 명시했다.
- 보류 기준의 잔차·후보 간격·비율·무변화 대조·4회 재검사와 개발/보정/평가 각 4설계 분리를 설명했다.
- 새 표 5에 미사용 주입 2,304건의 기존/새 기준 정답 487/615, 보류 1,817/1,689, 오진 0/0과 무주입 대조 오경보 0/64를 제시했다.
- 확정 615건의 ±0.01 dB 재검사를 16회로 늘려도 후보 반전이 없었다는 사후 확인과 기본 4회 유지 결정을 반영했다.
- 대조·안정성 조건의 개별 추가 기여, LLM의 추가 기여, 큰 모델 오차의 진단 개선이 확인되지 않았다는 한계를 포함했다. 관찰 오진 0을 미래 오류 보증으로 해석하지 않는다.
- 6절 결론의 후속 과제를 환경·모델 변화 설명과 실제 측정 불확실성 검증으로 갱신했다. 표의 수치를 반복하던 설명 두 문단을 줄였으며 기존 결과 분모는 합산하지 않았다.

## 확인 결과

- 최종 렌더 **3쪽** 전부 육안 확인. 한글·수식·표·그림의 잘림이나 겹침 없음.
- 공식 KIPS 양식과 `styles.xml`, 두 section의 A4·여백·2단 설정 정확히 일치.
- 기존 결과표 4개는 XML 그대로 보존. 결과표 총 5개, 편집 가능한 공진식 1개, 그림 1개. 제목 배치용 표는 별도다.
- 원본 DOCX의 `word/document.xml`만 변경. 기존 원고 SHA-256 유지.
- 관련 6개 실험의 프로토콜·감사 12개 파일과 고정 입력·행별 해시를 대조했다. 표 5 및 손실·진단 비교 수치는 완료된 감사 집계와 일치한다. 이번 문서 작업에서 실험을 새로 실행하지 않았다.
- 접근성 high/medium/low 0, 주석 0, 추적 변경 0, 중복 문단 ID 0. 숨은 작성자 메타데이터는 비어 있다.
- 최종 SHA-256: `f4151c2c3f6eb956162e9ee818288a7474f87c2f0c003d94fc513186f56e9856`.

문서에는 공식 양식의 글꼴을 유지했고 로컬 렌더에만 기존 fontconfig 대체 글꼴을 사용했다. 실제 제출 미리보기에서도 3쪽과 한글 표시를 확인한다.

## 재현과 근거

번들 Python으로 `scripts/update_paper_diagnosis.py`를 실행해 기존 원고의 필요한 부분만 수정한다.
`scripts/audit_paper_diagnosis.py --template <공식 양식 DOCX>`로 문서 구조·원본 보존·수치·렌더 페이지를 확인한다.
렌더는 documents 스킬의 `render_docx.py`와 번들 LibreOffice를 사용한다.
내부 검증 자료는 `build/paper_diagnosis_update/changes.json`, `verification.json`, `a11y.json`, `render/`에 있다.
상세 실험 결과는 `docs/lossy_repair_v1_results.md`, `diagnosis_visibility_v1_results.md`,
`reference_diagnosis_v2_results.md`, `abstention_calibration_v1_results.md`, `stability_extension_v1_results.md`를 따른다.
