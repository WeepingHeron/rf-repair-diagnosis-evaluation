# 고장 전 기준 측정 비교 v2: 적격 부분집합의 탐색

2026-09-06. v1 사전 검증에서 257 MHz 정상 설계의 S11=−13.170451 dB가
기존 −15 dB 문턱을 넘었다. 예정했던 8사례 v1은 계획대로 API 0회에서 중단했다.
`experiments/reference_diagnosis_v1.json`의 ABORTED_PRECHECK 기록과 모든 실패 데이터를 보존한다.

이번 v2는 **v1 사전 검증 결과를 본 뒤 정한 별도 탐색**이다. v1 전체 평가의 성공으로
표현하지 않는다. 모델 응답이나 역추정 결과를 보기 전에, 정상 PASS·고장 FAIL·oracle PASS인
3설계·6고장(reference_d1..d3)을 선택했다. d4의 2고장을 제외하며 새로운 사례로 교체하지 않는다.
회로값·난수·사양·손실 모델을 수정하지 않는다. 해당 적격 집합 밖으로 일반화하지 않는다.

## 고정 조건

측정 정보, 9주파수, 0.01 dB 정밀도, 402회 역추정 계산 상한, RMSE 기준, prompt/schema는
[v1 계획](reference_diagnosis_v1_protocol.md) 그대로다. 정상값이나 고장 위치를 직접 제공하지 않는다.
조건은 current_only / historical_reference / reference_with_fit이다.
세 조건 각각 6사례×2반복=12회, **전체 API 상한 36회**다.
모델 gpt-5.6-luna low, 출력 상한 2000토큰, 자동 재시도 0회, store=false, unknown 허용.
세 조건 순서를 사례·반복마다 순환한다. 요청마다 독립된 context를 사용한다.

수치 역추정 기준선은 선택한 6사례에서 따로 집계하고 모델 입력과 동일한 계산 결과를 쓴다.
LLM의 진단을 복구 결과로 교정하거나 보류를 정답으로 세지 않는다.
API 실패도 계획 분모 12에 포함하며 수치 계산비용과 API 호출을 분리한다.
사전 검증의 8사례는 모두 감사하고, 비교의 6사례와 혼동하지 않는다.

이는 가정한 고장 전 기준 측정이 실제 운용에서 저장돼 있는 상황의 합성 모사다.
현재 회로값과 고정 모델이 정확하며, 잡음·drift가 없고 단일 값만 달라졌다는 강한 가정이 있다.
실계측·실제 제품·복수 고장 성능으로 해석하지 않는다. 이전 실험·논문 분모에 합산하지 않는다.
