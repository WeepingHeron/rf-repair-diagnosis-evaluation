# 비이상적 소자 조건 확인: 고정 계획

2026-09-06. 기존 v4/v5와 정합 파일럿 이후 정한 탐색적 조건 확인이다.
이번 단계는 로컬 ngspice 실험이며 API 호출 예산은 0회다. 이전 원고와 고정 실험은 변경하지 않는다.

## 질문과 사전 조건

유한 Q·기생 성분·L/C 공차가 있을 때 기존 BPF 성능 제약을 그대로 만족하는
정상 회로가 남는지, 남는 조건에서 단일 값 고장과 결정적 공진 복구를 평가한다.
정상 FAIL은 기준 설계의 적용 범위 문제이며 복구 알고리즘 실패율에 넣지 않는다.
그렇다고 해당 조건을 삭제하지도 않는다. 모든 조건과 탈락 원인을 기록한다.
정상 FAIL은 어떤 재설계로도 달성 불가능하다는 증명이 아니다.

## 고정한 조건

- 새 설계: 103/139/167/211 MHz, 상대 대역폭 12/14/16/18%, 50 Ω 포트.
- Q: 이상적 무손실, 200, 100, 50. L과 C에 같은 명목 Q를 적용한다.
- R_L=2πf₀L_nom/Q, R_C=1/(2πf₀C_nom Q). f₀와 명목값에서 한 번 계산한 직렬 R을
  주파수·공차·고장·수정에 따라 다시 계산하지 않는다. 따라서 전체 소자의 유효 Q가
  전 주파수에서 일정하다는 모델이 아니다.
- 기생 성분 off/on: L의 전체 직렬 RL 가지에 병렬 Cp=0.1 pF, C에 직렬 ESL=0.2 nH.
- 주 L/C 여섯 개 공차: 0%, 또는 ±1/3/5% 균등 분포의 고정 난수 3회.
  같은 설계에서는 Q/기생 조건에 같은 난수 벡터를 쓰고 공차 폭만 스케일한다.
- 총 4×4×2×(1+3×3)=320개 정상 조건, 각 2고장으로 640개 고장 조건.
  난수 seed 202609063. 고장은 사전 지정한 주 L/C를 0.55배 또는 1.8배로 바꾼다.
  각 oracle은 고장 직전의 공차 포함 값으로 되돌리며 다른 공차/기생/저항은 유지한다.

기존 7개 판정 제약을 유지한다: peak 주파수 오차 ≤2%, 중심 S21≥−0.25 dB,
중심 S11≤−20 dB, 두 통과대역 가장자리 S21≥−4 dB, 두 저지대역 S21≤−15 dB.
0.5f₀–1.5f₀, 2001점으로 측정 주파수가 정확히 포함된다.
결과를 본 뒤 문턱이나 난수, 설계를 바꾸지 않는다.

## 결정적 기준선과 해석

정상 PASS·고장 FAIL·정확한 one-edit oracle PASS인 조건에서만 복구율을 센다.
관측된 주 L/C의 원래 단자 연결과 현재값으로 이상적 LC 공진 후보를 계산한다.
기생 소자를 추가하면 기존 문자열 파서가 원래 LC 쌍을 잃을 수 있으므로, 생성된
소자 모델의 공개된 주 회로 연결 정보를 사용한다. 정상값이나 고장 위치는 넘기지 않는다.
이 기준선은 기생값을 보상하는 새 최적화기가 아니라 연결 관계를 아는 이상적 공진 계산이다.
큰 공진 오차 순·부품명 순으로 최대 3후보, 성공 시 중단하며 각 후보는 최초 고장 회로에서 시작한다.
주 L/C 한 값만 수정 가능하며 기생 C/L, 손실 R, 포트는 보호한다.

모든 원본 회로·SPICE 표·판정·분모를 보존한다. 별도의 ABCD 임피던스 계산으로
S-parameter를 비교하고 집계와 고정 hash를 감사한다. 공차 3회와 설계 4개는
제조 수율을 추정하기에 충분하지 않으며 320개 독립 설계로 해석하지 않는다.

## 물리 모델 출처와 경계

Q와 주파수 의존성, 인덕터 자체 공진의 병렬 기생 C 모델은
[Coilcraft](https://www.coilcraft.com/en-us/resources/application-notes/testing-inductors-at-application-frequencies/),
커패시터 ESR/ESL 등가 모델은
[Murata](https://article.murata.com/en-eu/article/impedance-esr-frequency-characteristics-in-capacitors)를 참고했다.
여기서 Q·Cp·ESL·공차의 숫자는 민감도 확인용 **Assumed/Synthetic** 값이다.
실제 부품 보증치, 실측, 제조사 광대역 모델, PCB 결합·온도·바이어스 모델이 아니다.
