# 작은 값 변화·비균일 오차 개발 집합: 고정 계획

2026-09-06. 기존 reference_robustness_v1에서 잔차 문턱에 따른 보류가 많았으므로,
새 설계의 작은 주 L/C 변화와 비균일 오차를 확인한다. **개발·진단용 실험이며 최종 평가가 아니다.**
기존 fit_reference와 보류 기준(최선 RMSE≤0.02 dB, 차선 RMSE≥0.10 dB)은 그대로 유지한다.
새 문턱을 최적화하거나 적용하지 않는다. API 호출 0회, 복구 제안·복구율 평가는 하지 않는다.

## 집합과 오차

- 설계: 127/173/217/269 MHz, BW 18/20/22/24%, seed 202609100..103, 주 L/C 제작 편차 ±2%.
- 각 설계의 주 L/C 6개 각각에 −10/−3/−1/+1/+3/+10% 값 변화를 주입: 설계당 36개, 총 144개.
- 각 설계에 주입 변화가 없는 대조군 1개 추가: 총 148개 상태.
- 작은 변화가 원래 성능 규격을 깨뜨린다고 가정하지 않는다. 정상과 주입 상태의 native SPICE
  판정을 기록하되, PASS·FAIL로 제외하거나 회로·규격·seed를 수정하지 않는다. 평가 대상은
  주입한 변화의 부품·방향이며 “수리가 필요한 규격 실패” 여부와 다르다.

| 프로파일 | 수준 | draw 수 |
|---|---|---:|
| clean | 0.01 dB 반올림만 | 1 |
| noise | 고장 전 27개 크기 값에 독립 정규잡음 σ=0.01 dB | 3 |
| drift_0.1pct | 현재 주 L/C 각각에 독립 Uniform[−0.1%, +0.1%] 변화 | 3 |
| drift_0.5pct | 현재 주 L/C 각각에 독립 Uniform[−0.5%, +0.5%] 변화 | 3 |
| model_10pct | 각 소자의 Rs 및 Cp/ESL 12개에 독립 Uniform[−10%, +10%] 불일치 | 3 |
| combined | σ=0.01 dB + 비균일 drift ±0.1% + 모델 불일치 ±10% | 3 |

16개 프로파일 ×148상태 = **2,368회 역추정**. 주입 변화 2,304건과 대조군 64건을 분리한다.
seed는 SHA256(diagnosis_dev_v1|design_id|draw|tag)의 앞 16자리 정수이며 tag는
noise/drift/model이다. 같은 설계·draw의 벡터를 주입 부품·변화량·대조군·프로파일 사이에 공유한다.
실제 장비 오차 자료가 아닌 합성 개발 조건이고, 2,368행을 독립 회로 표본으로 간주하지 않는다.

추정기는 현재 주 L/C 값, 기존 공개 모델, 고장 전 9주파수 S11/S21/S22 크기만 본다.
측정 생성용 실제 소자별 모델·과거 부품값·오차 벡터·주입 부품은 전달하지 않는다.
모델 오차는 각 소자별 Rs와 L의 Cp 또는 C의 ESL에 적용하며 기존 모델은 추정기에서 유지된다.
drift는 기준 측정 후의 현재 주 L/C에 적용하며 바뀐 현재 주 값은 알려진다는 기존 가정을 유지한다.

## 기록과 검증

현재 판정의 정답·오진·보류, 대조군 오경보, 최상위 가설의 위치·방향 정답을 집계한다.
추가로 E0(현재값을 과거에도 그대로 쓴 무변화 가설의 RMSE), E1(최선), E2(차선),
E2−E1, E0−E1, 최상위 가설이 추정한 주 값 변화량을 기록한다. E0는 현재 모델 기준의
무변화 가설이며 환경 drift까지 적합한 무고장 모형은 아니다. 새 보류 규칙에 적용하지 않는다.

모든 입력·원시 결과를 저장한다. 모든 역추정을 재실행하고 점수·특징·집계를 독립 재계산한다.
고유 과거 물리 회로와 baseline 148상태를 native ngspice로 실행하고 전체 주파수 ABCD,
9주파수 nodal 해석으로 확인한다. 각 fit의 최선·차선 잔차도 독립 nodal 계산으로 확인한다.
이후 보류 기준은 개발 집합의 가설 분리·오경보·진단 비율을 보며 설계하되,
조정 후에는 미사용 **설계 단위** 평가 집합에서 검사해야 한다. 이번에는 문턱을 바꾸지 않는다.
