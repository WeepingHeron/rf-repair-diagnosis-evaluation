# 작은 값 변화와 비균일 오차: 개발 확인 및 보류 기준 설계

**보류 기준을 일괄 완화하면 안 되는 반례를 확인했다.** 고정된 기존 기준에서 주입 변화 2,304건은 정답 509, 보류 1,795, 오진 0이었다. 최상위 부품·방향 후보가 틀린 385건은 모두 보류됐다. 값 변화를 주입하지 않은 대조군 64건의 단일 부품 오경보는 0이었다.

2026-09-06. API 0회, 별도 개발 집합 4설계·2,368행. 새 보류 기준을 선정하거나 적용하지 않았다. 이전 945행과 합산하지 않으며 실측 성능·최종 holdout 결과가 아니다. **기준 상태부터 규격 FAIL인 설계도 1개 포함한다** (diagdev_d2_control). 사전 계획대로 규격 만족 여부로 제외하지 않았다. 여기서 확인하는 것은 주입한 값 변화의 부품·방향이며, 수리가 필요한 성능 불량 여부와 구별한다.

## 지금 보류 기준은 무엇인가

각 부품 하나가 달라졌다는 가설로 과거 측정값을 재현하고, 27개 dB 값의 RMSE를 구한다. E1은 가장 작은 RMSE, E2는 두 번째로 작은 RMSE다. 현재는 다음 두 조건을 **모두** 만족할 때만 최상위 부품과 방향을 확정한다.

```text
E1 ≤ 0.02 dB   AND   E2 ≥ 0.10 dB
하나라도 만족하지 못하면 component=unknown
```

첫 조건은 가장 좋은 설명도 측정과 잘 맞는지 검사한다. 두 번째는 다른 부품 가설도 비슷하게 측정을 설명하는지를 거른다. **현재 두 번째 조건은 E2 자체에 대한 문턱이며 E2−E1≥0.10 dB가 아니다.** 두 수치는 거의 무오차·0.01 dB 반올림 조건에서 정한 가정이고, 실측 자료로 교정한 허용치나 99% 신뢰도 같은 확률을 뜻하지 않는다.

### 두 종류의 보류를 실제 사례로 보면

- 잘 맞는 후보가 있어도 차선 문턱에 걸린 사례: `clean/diagdev_d3_C751_m1`, 후보 C751, E0=0.78517, E1=0.00251, E2=0.05470, 간격=0.05219 dB. 현재 판정은 보류다.
- 모델·환경 오차 때문에 최상위 후보 자체가 틀린 사례: `combined_1/diagdev_d2_L932_m1`, 후보 C266, E0=1.37324, E1=0.05877, E2=0.11408, 간격=0.05531 dB. 현재 판정은 보류다.
- 값 변화가 없는 대조군에도 부품 가설이 생기는 사례: `model_10pct_2/diagdev_d1_control`, 후보 C830, E0=0.68101, E1=0.08063, E2=0.10850, 간격=0.02787 dB. 현재 판정은 보류다.

두 번째 사례의 E1=0.0588 dB, E2=0.1141 dB를 보면, **E1 문턱만 0.10 dB로 늘리면 기존 E2 조건도 통과해 오답을 확정하게 된다.** 세 번째 대조군도 같은 완화에서 오경보가 된다. 이는 저장된 점수에 대한 논리적 반례이며 새 규칙을 채택하거나 전체 성능을 재평가한 결과는 아니다.

## 보류 기준을 정하는 순서

1. **오류의 비용과 평가 지표를 먼저 정한다.** 확정 진단 중 오진 비율, 무주입 대조군의 오경보 비율, 확정 진단을 내리는 비율을 함께 본다. 전부 보류하면 오진은 0이지만 쓸모 있는 진단도 0이므로 오진만 최소화하지 않는다. 허용 오류 수준을 먼저 정하고 그 조건에서 진단 비율을 높이는 방향이다. 이 관계는 선택적 예측의 risk–coverage 관점과 연결된다. [Geifman & El-Yaniv, 2017](https://arxiv.org/abs/1705.08500).

2. **기준 측정의 오차와 무고장 변화를 따로 추정한다.** 정상 상태 반복 측정, 자연적인 소자 변화, 주파수 교정·모델 불일치가 만드는 잔차를 개발 자료에서 확인한다. 소자·채널별 오차가 다르면 오차 크기로 정규화하거나 공분산을 반영한 잔차를 검토할 수 있다. 지금 정규 dB 잡음은 계측 자료가 아니므로 그대로 장비의 허용치로 쓰지 않는다.

3. **설명 적합성·후보 분리·변화 증거를 함께 검사하는 규칙을 만든다.** 예를 들어 E1이 오차 범위 안인지, E2−E1 간격이 충분한지, 단일 고장 가설이 무고장·자연변화 가설보다 충분히 나은지를 본다. 현재 기록한 E0−E1은 참고 특징이다. E0는 drift까지 설명한 무고장 모형이 아니므로, 이 값이 크다는 이유만으로 고장을 확정하면 안 된다. 위의 대조군에서도 개선량이 컸다. 작은 측정 섭동에 후보가 자주 바뀌면 보류하는 안정성 기준도 개발 자료에서 검토할 수 있다.

4. **개발·보정·최종 평가를 설계 단위로 분리한다.** 개발 자료로 규칙 형태를 정하고, 별도 보정 자료로 숫자를 정한 후 동결한다. 새로운 설계의 최종 평가에서는 숫자를 바꾸지 않고 진단 비율·오진·오경보를 보고한다. 같은 회로의 난수 반복을 양쪽에 나눠 놓으면 설계가 누설될 수 있다. 유한 표본의 불확실성도 고려해야 하므로 4설계의 2,368행만으로 작은 오류 확률을 보장하지 않는다.

**현재 제안은 기준 설계 절차이며, 새 숫자를 확정한 것은 아니다.** 이번에는 기존 0.02/0.10 dB를 유지했다. 먼저 소자·측정 오차를 허용하는 무고장 모형과 작은 변화의 구분 가능성을 개선해야 한다. 후보 순위가 틀리는 조건에서는 잔차 문턱 완화만으로 문제를 해결할 수 없다.

## 검증 기록

- 입력·가설·점수 2,368건을 전부 재생성·재실행. fit 전방 계산 951,936회, 무변화 가설 계산 2,368회.
- 고유 과거 회로와 baseline 상태를 합친 native sweep 160개, 전체 320,160주파수 점을 ABCD와 대조.
- 독립 nodal로 생성 회로 1,440점과 E0/E1/E2의 63,936점을 검증. 반올림·잡음 측정값 63,936개 재계산.
- 최대 native 크기 차이 1.82e-09, nodal 크기 차이 1.77e-09 (각 한계 2e-7). 특징 재계산 차이 1.1e-08 (한계 1e-7).
- 단위 검사 74개 통과. 기존 실험 입력·코드·문턱과 제출 원고는 보존.

**검증 판단: 개발 실험과 한계를 명시하면 공유 가능.** 미해결 계산 불일치는 없지만, 4설계·3난수 draw, 주 값이 정확히 알려진 단일 주입 변화와 제한적 모형이라는 한계가 있다. 기준 상태가 규격을 만족하지 않는 설계도 포함했다. 이번 자료는 규칙을 만드는 개발 근거이며 최종 일반화 성능이나 실제 장비의 오경보 보증으로 사용할 수 없다.
