# 고장 전 주파수 응답을 추가한 진단 비교: 사전 계약

2026-09-06. 후보 공개 시점 비교의 높은 판단 보류 이후 정한 새 탐색 실험이다.
실제 계측 데이터가 아니라 저장된 고장 전 주파수 응답을 **ngspice로 모사**한다.
운용 전 기준 sweep이 저장돼 있다는 추가 가정을 두며 모든 시스템에서 확보 가능하다고 주장하지 않는다.

## 새 사례와 측정

115/153/203/257 MHz, BW 16/18/20/22%, seed 202609090..202609093,
설계별 ±2% 공차 벡터 1개와 사전 지정한 0.55배/1.8배 단일 L/C 고장 2개를 사용한다.
lossy_repair_v1의 보상 설계·손실/기생 모델·사양은 그대로다. 8사례 모두
정상 PASS·고장 FAIL·정답 한 값 복원 PASS를 확인한다. 부적격이면 사례를 바꾸지 않고 중단한다.

0.70/0.85/0.92/0.96/1/1.04/1.08/1.15/1.40 f₀에서 고장 전후의 S11/S21/S22 크기를
native SPICE 표로부터 추출한다. 9×3=27값을 0.01 dB로 반올림하며 위상·추가 잡음·
계측기/환경 drift는 없다. 모델 계산값을 측정값으로 둔갑시키지 않고 합성 기준 측정으로 표시한다.
정상 부품값·정상 netlist·고장 위치는 요청에 넣지 않는다. 전후 spectrum의 주파수와 정밀도는 같다.

## 세 조건

1. current_only: 현재 회로·공개 모델·사양·현재 SPICE metric·현재 9주파수 spectrum.
2. historical_reference: 위 입력 + 고장 전 9주파수 spectrum.
3. reference_with_fit: 위 입력 + 고장 전 spectrum에 맞춘 부품별 역추정 결과.

모든 조건의 진단 전용 prompt/schema는 동일하며 unknown을 허용한다.
고장 방향은 현재값이 고장 전 값보다 큰지/작은지다. 호출당 한 번 진단하고 소급 교정하지 않는다.
각 조건 8사례×2반복=16회, 총 48 API 호출, gpt-5.6-luna low, 출력 상한 2000토큰,
자동 재시도 0회, store=false다. 조건 순서는 사례/반복마다 세 순서를 회전해 균형을 맞춘다.
모든 요청은 독립적이며 다른 조건의 답을 넘기지 않는다. 요청 필드 차이가 정의된 추가 정보뿐인지 감사한다.
호출 수·출력 상한이 같아도 입력 토큰이나 수치 계산량까지 동일한 것은 아니다.

## 결정적 역추정 기준선

현재 6개 주 L/C 각각 하나의 과거값을 가정해, 나머지 현재값을 고정한 채
고장 전 27개 측정치와 모델 예측의 dB RMSE를 최소화한다.
현재값의 0.4–2.5배 log grid 41회 + golden-section 초기 2회/추가 24회,
부품당 최대 67회, 사례당 최대 402회 전방 계산이다. 각 계산은 9주파수를 평가한다.
고장 manifest·실제 과거값은 사용하지 않는다.

최선 RMSE≤0.02 dB, 차선 RMSE≥0.10 dB일 때만 탐색 범위 내 식별로 표시한다.
그 외는 판단 보류다. 이 문턱은 사례 결과를 보기 전에 고정하며, 0.01 dB 반올림만 있는
이상화된 측정 조건의 가정이다. 전체 파라미터 공간의 유일성이나 실제 계측 잡음에서의 식별 증명은 아니다.
최상위 가설의 역추정값으로 한 값을 바꾸고 native SPICE로 복구를 확인하지만,
그 결과를 LLM 요청에 추가하거나 실패 사례를 제외하지 않는다.

## 지표와 검증

위치·방향 정답, 위치 정답, 오진, 판단 보류, API 실패를 계획 분모 16에 대해 보고한다.
결정적 역추정 진단은 8사례로 별도 집계한다. 각 LLM 조건의 최상위 가설과의 일치도,
기준 측정 전/후 및 역추정 추가 전/후의 짝 비교를 기록한다.
정상 상태 spectrum의 추가는 새 정보의 효과이고, 역추정 추가는 그 정보의 계산 보조 효과다.
LLM이 이미 정답인 결정적 가설을 반복한 경우 LLM 자체가 원인을 새로 찾아냈다고 주장하지 않는다.

모든 회로·native 표·측정 추출·원시 응답·ID·usage·입력 hash를 보존한다.
9주파수 추출과 반올림을 독립 재계산하고, 모든 회로를 native SPICE 재실행 및 nodal 계산으로 검증한다.
역추정 탐색도 재실행한다. 작은 합성 표본·정확한 현재 부품값·고정된 공개 모델·drift 없는 기준 측정의
한계를 명시하며 기존 실험이나 논문 분모에 합산하지 않는다.

API는 이미 승인한 기존 키를 재사용한다. 외부에는 수식 생성 합성 회로와 수치만 보낸다.
