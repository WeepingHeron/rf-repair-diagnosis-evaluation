# 다중 보류 기준의 보정과 설계 단위 미사용 평가

2026-09-06. 사용자 요청에 따라 진단용 보류 정책을 새 버전으로 구현한다.
개발 자료는 diagnosis_development_v1의 4설계다. 아래 새 보정·평가 설계는 개발과
분리하며, 최종 평가 전에 선택한 정책과 보정 결과를 hash로 고정한다. API 호출 0회.

## 기준의 형태와 선택 규칙

E0=현재값을 과거에도 적용한 무변화 가설 RMSE, E1/E2=최선/차선 가설 RMSE.
0.01 dB는 점수 분모의 고정 바닥값이며 실제 계측 분산 추정치가 아니다.

1. 적합성: E1≤τfit. 기존 0.02 dB를 넘겨 완화하지 않는다.
2. 가설 구분: E2−E1≥τgap 및 E2/max(E1,0.01)≥τratio.
3. 무고장 대조: T=(E0−E1)/max(E1,0.01)≥τnull.
   τnull=max(1, 1.1×max(보정 무주입 대조군 T, 0)). 1.1은 사전 고정한 경험적 여유다.
   여러 부품·손실·기생 변화가 있는 대조군을 포함한다. 이는 무고장 물리 모형의 최적 적합이나
   확률적 위험 보증이 아니며, 알려진 합성 대조군의 점수 상한을 이용하는 규칙이다.
4. 안정성: 입력 측정 27개 값에 각각 ±0.01 dB를 더한 4개 고정 재검사에서,
   6부품의 역추정을 다시 실행해 최상위 부품과 방향이 4/4 일치해야 한다.
   재검사 seed는 SHA256(abstention_v1|정렬 직렬화 입력)의 앞 16자리 정수로 정하고
   getrandbits(1) 부호를 사용한다. 실제 잡음 확률 또는 신뢰도로 해석하지 않는다.

고정 후보 격자는 τfit={0.01,0.015,0.02}, τgap={0.015,0.03,0.05,0.08},
τratio={3,5,10}, 총 36개다. τnull은 보정 대조군에서만 계산한다.
보정에서 **관찰 오진 0·오경보 0**인 후보 중 확정 정답 수가 가장 많은 후보를 선택한다.
동률은 τfit가 작은 순, τgap가 큰 순, τratio가 큰 순이다. 인구집단의 오류 확률이 0이라는 뜻은 아니다.
모든 후보가 통과할 수 없는 입력은 안정성 검사를 생략한다. 사전 조건은
E1≤0.02, 간격≥0.015, 비율≥3이며 생략 자체가 최종 확정을 허용하지 않는다.

## 데이터와 분모

| 용도 | 주파수 MHz | BW | seed |
|---|---|---|---|
| 기존 개발 | 127/173/217/269 | 기존 그대로 | 기존 그대로 |
| 보정 | 133/179/227/283 | 18/20/22/24% | 202609110..113 |
| 최종 평가 | 147/193/251/307 | 18/20/22/24% | 202609120..123 |

각 설계는 6개 주 부품×±1/3/10% 주입 36상태와 무주입 대조군 1상태.
diagnosis_development_v1의 같은 16개 오차 프로파일을 사용하되 설계 ID별 seed로
새 벡터를 만든다. 각 분할 148상태×16=2,368행(주입 2,304, 대조 64), 총 4,736행.
기존 일반화 논문 결과에 합산하지 않는다. 주파수·회로·오차 난수·예산을 결과에 따라 바꾸지 않는다.
주입 변화 식별을 평가하므로 정상 규격·주입 후 규격 판정을 기록하되 PASS/FAIL로 제외하지 않는다.
물리적 일반화 범위는 같은 수동 BPF 구조와 합성 오차 모형 안이다.

보정 데이터 수집 → 정책 선택·저장 → 미사용 데이터 수집 순서를 강제한다.
평가를 본 뒤 문턱·사례를 다시 고르지 않는다. 같은 입력에서 기존 E1≤0.02 & E2≥0.10과 비교한다.
새 정책은 추가 재검사 계산을 사용하므로 같은 계산 예산의 성능 비교라고 주장하지 않는다.

## 적용과 검증

최종 평가에서 새 정책의 관찰 오진·오경보가 모두 0이고 확정 정답 수가 기존 정책 이상이면
별도의 새 진단 명령 기본 정책으로 연결한다. 실패하면 새 정책은 보정된 실험 정책으로 보존하고
기본 활성화하지 않는다. 이 적용 여부 검사는 위험 보증이나 또 다른 튜닝이 아니다.
기존 동결 실험의 기준·결과는 덮어쓰지 않는다.

전 분할의 역추정·재검사를 재실행하고 후보 선택, 대조군 상한, 스코어, 진단 사유를 재계산한다.
고유 과거 회로 및 baseline 상태는 native SPICE·독립 nodal로 검증하고 E0/E1/E2 잔차도 nodal로 확인한다.
재검사 입력·가설·호출 계산을 저장한다. 단위 검사에는 잘못된 정책, 모호한 후보, 무고장 및 안정성 보류를 포함한다.
개별 확정은 실제 계측 보증, 부품 고장 확률 또는 실제 수리 승인으로 해석하지 않는다.
