# 확정 진단의 재검사 4회→16회 확장

2026-09-06. 사용자가 요청한 추가 재검사 계산이다. 기존 abstention_calibration_v1
미사용 평가에서 **활성 정책이 확정한 615건 모두**를 대상으로 하며, 정답 여부로 선별하지 않는다.
기존 보류 1,689건과 무주입 대조군 64건은 이번 조건부 확정 진단 안정성 검사의 대상이 아니다.
이전 결과를 본 뒤 정한 추가 스트레스 확인이며 새 holdout 성능 평가나 위험 확률 검증이 아니다.

각 입력의 기존 seed와 난수 스트림을 그대로 이어 측정 27개 값에 ±0.01 dB를 더한
16개의 독립 부호 벡터를 생성한다. 기존 1~4회 입력·fit은 원본과 일치함을 확인하고 재사용한다.
**추가 5~16회: 615×12=7,380회 역추정**, 기존 포함 총 9,840회 재검사다.
원래 측정값에 각 벡터를 독립 적용하며, 이전 재검사 값에 누적하지 않는다.
6부품의 값을 다시 최적화하여 최상위 부품과 방향이 원본 fit과 모두 같은지 확인한다.
각 fit은 기존 402회 전방 계산 상한과 같은 9주파수 모형을 쓴다. API 호출은 없다.

모든 재검사를 마친 뒤 원본과 16/16 일치한 진단 수, 부품 반전·방향 반전 횟수,
입력별 첫 불일치 회차를 집계한다. 실패·불일치는 제외하거나 다시 뽑지 않는다.
만약 16/16을 요구했다면 보류로 바뀔 확정 진단 수도 표시하되, 활성 기본 정책의
4/4 조건이나 기존 실험 결과는 변경하지 않는다. 한 입력의 반복을 독립 회로로 세지 않는다.

코드·이 계획·정책·활성 설정·원본 감사·대상 행 hash를 계산 전에 고정한다.
615개 선정과 첫 4회 재사용을 검증하고 추가 7,380개 fit을 모두 재실행한다.
추가 fit의 최선·차선 RMSE는 9주파수의 독립 nodal 해석으로 확인한다.
새 물리 회로나 진짜 계측을 만드는 실험이 아니므로 기존 native 물리 검증을
hash로 참조하며 새 native sweep이나 실제 반복 측정을 수행했다고 주장하지 않는다.
결과는 같은 ±0.01 dB 조건에서의 반복 횟수 증가 효과로만 해석한다.
