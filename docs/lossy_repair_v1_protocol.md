# 손실을 반영한 정상 설계와 복구 비교: 사전 계약

2026-09-06. nonideal_screen_v1의 사양 부적합을 확인한 뒤 설계한 별도 탐색 실험이다.
이전 −0.25 dB 실험의 사양이나 판정은 바꾸지 않는다.

## 개발 단계와 평가 기준

개발 회로는 이전 조건 확인에 사용한 103 MHz에서 BW=18%, seed=202609070,
주 L/C의 고정 ±2% 공차다. 기존 이상적 Butterworth 리액턴스를 중심 주파수에서
재현하도록 L의 병렬 Cp와 C의 직렬 ESL을 보상한다. 손실의 실수부는 남는다.
L은 복소 임피던스의 허수부를 이분법으로 맞추고 C는
C_new=1/(1/C_ideal+ω₀²·ESL)로 계산한다. 광대역 최적 설계나 제조 수율 보장이 아니다.

초기 개발용 ESR 조합 L=0.25 Ω/C=0.05 Ω은 중심 손실 약 2.82 dB로 탈락했다.
L=0.05 Ω/C=0.02 Ω은 약 0.79 dB로 통과했다. C=0.01 Ω도 확인했지만 채택하지 않았다.
이 선택은 **개발 회로 결과를 본 뒤 한 선택**으로 기록하며 평가 사례에서는 다시 조정하지 않는다.

사전 고정할 탐색적 성능 예산:

- 중심 S21≥−2 dB: 정합된 조건에서 전력 전달 약 63% 이상을 목표로 하는 손실 예산.
- 중심 S11≤−15 dB: 반사 전력 약 3.2% 이하.
- peak 위치 오차≤3%, 양 통과대역 가장자리 S21≥−6 dB, 두 저지대역 S21≤−12 dB.
- 측정 0.5–1.5 f₀ 2001점, 기존과 같은 정확한 5개 측정 위치.

이는 특정 수신기·고객·표준에서 요구한 제품 규격이 아닌 **Assumed 연구 기준**이다.
추후 실제 제품 적용에는 해당 용도의 손실·대역·정합 예산을 별도로 정해야 한다.

## 공개 소자 모델과 미사용 사례

고정 ESR은 L 모두 0.05 Ω, C 모두 0.02 Ω이다. L에는 Cp=0.1 pF,
C에는 ESL=0.2 nH를 추가한다. 이 숫자는 합성 가정이며 제조사 보증치가 아니다.
각 소자의 Q는 값과 주파수에 따라 달라진다. ESR을 부품의 정상값/Q로부터 생성하지 않으므로
공개 ESR을 역산해 정상값을 직접 복원할 수 있는 인위적 지름길을 피한다.
R/Cp/ESL/포트는 고장과 수정 시 고정되며 주 L/C 한 값만 수정할 수 있다.

평가용 새 설계는 109/143/191/229 MHz, BW 16/18/20/22%,
seed=202609071..202609074의 고정 ±2% 공차 각 1회다. 설계당 사전 지정한
2개 L/C를 0.55배/1.8배로 바꿔 총 8고장을 만든다. 모든 생성 사례를 보존한다.
정상 PASS·고장 FAIL·정확한 한 값 oracle PASS를 검증하고, 미달이면 해당 사례를
제외한 이유를 남긴다. 평가 결과를 보고 공차·사양·사례·정책을 조정하지 않는다.
정상 4개 전부 통과하지 않으면 live LLM 비교를 시작하지 않고 개발 단계 문제로 기록한다.

## 비교와 예산

1. 이상적 LC 공진 후보: 공개 주 회로 연결·현재값만 사용, 최대 3개 native SPICE 후보.
2. 손실 모델 수치 탐색: 6부품 각각 현재값의 0.4–2.5배 log grid 41개와
   최선 구간의 golden-section 초기 2회+추가 16회, 좌표별 최대 59회/전체 최대 354회
   ABCD 전방 모델 계산. 각 계산은 2001주파수 전부를 평가한다. 부품별 최선 후보를
   점수/이름으로 정렬해 상위 3개를 native SPICE로 확인, 첫 성공 시 중단한다.
3. 계산 보조 LLM: 같은 수치 탐색 결과와 관측 회로, 사양, 최초 native metric을 제공한다.
   실패 시 실제 metric 피드백을 제공하며 후보 밖의 허용 수정도 가능하다.
   gpt-5.6-luna low, 출력 2000토큰, 최대 3회 호출/3후보, 8사례×2회=16경로,
   API 최대 48회. 미완료 응답도 실패로 포함하며 자동 API 재시도는 없다.

수치 탐색과 LLM은 같은 사전 계산을 공유한다. 최대 native 후보 평가 예산은 모두 3회다.
이상적 LC 조건은 전방 탐색을 수행하지 않으므로 **전체 계산비용까지 동일한 비교가 아니다**.
ABCD 탐색 횟수와 native SPICE 횟수, API 호출·usage를 별도로 보고한다.
결정적 결과의 8사례와 LLM 16경로는 독립 표본 수로 합치지 않는다.
정상 netlist·명목값·고장 위치·oracle은 어떤 정책 입력에도 넘기지 않는다.

고정 파일: `experiments/lossy_repair_v1.json`. API는 사용자가 승인한 기존 키를 재사용한다.
외부 전송은 수식으로 새로 생성한 합성 회로·수치·시뮬레이션 결과뿐이다.
논문 원문·개인정보·사용자 소유 실제 회로를 전송하지 않는다.

## 검증과 근거

개발용 L 손실/C 손실/Cp/ESL의 16조합 제거 실험을 별도 보존한다. 이는 고정한
보상 설계에서 한 모델 항을 제거하는 분석이며 각 조합을 다시 최적화하지 않는다.
원본 응답·request·metric·source hash를 보존하고, 모든 최종 후보를 native SPICE로
재실행한다. ABCD 전방 모델은 실제 회로 파일의 부품값을 읽은 별도 nodal 계산으로 검증한다.

모델 형태는 [Coilcraft](https://www.coilcraft.com/en-us/resources/application-notes/testing-inductors-at-application-frequencies/)와
[Murata](https://article.murata.com/en-eu/article/impedance-esr-frequency-characteristics-in-capacitors)를 참고한다.
단가는 [OpenAI 공식 문서](https://developers.openai.com/api/docs/models/gpt-5.6-luna)의
input/cached/write/output 백만 토큰당 $0.20/$0.02/$0.25/$1.20를 사용한 추정치다.
