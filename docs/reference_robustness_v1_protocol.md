# 기준 측정 역추정의 오진·보류 민감도: 고정 계획

2026-09-06. API 없이 reference_diagnosis_v2의 결정적 역추정만 검사한다.
이전 사전 검증에서 선택된 115/153/203 MHz 3설계·6고장을 재사용하므로 새 holdout이나
성능 일반화 실험이 아니다. 같은 설계의 고장 없는 상태 3개를 대조군으로 추가한다.
정상 대조군은 단일 부품 고장 진단을 보류해야 한다. 환경에 따라 규격을 만족하는지와는
별개이며, 여러 부품이 함께 변하는 drift를 한 부품 고장으로 특정하면 오경보다.

## 고정 조건

- 기존 fit_reference를 수정 없이 사용: 9주파수×S11/S21/S22 크기, 현재값의 0.4–2.5배
  탐색, 부품당 최대 67회(총 402회). 최선 RMSE≤0.02 dB와 차선 RMSE≥0.10 dB일 때만 특정.
- 추정기에 주는 정보는 현재 주 L/C 값이 담긴 netlist, 기존 공개 모델, 고장 전 spectrum뿐이다.
  정상값·정답·실제 모델·섭동 파라미터는 추정기에 전달하지 않는다. current spectrum은 이
  역추정 함수에서 쓰지 않으므로 이번 평가에 사용하지 않는다.
- 고장 전 spectrum은 별도 물리 모델의 ABCD로 생성하고 오차를 더한 뒤 0.01 dB로 반올림한다.
  전기적 spectrum은 native SPICE와 독립 nodal 계산으로 확인한다. 합성 잡음 자체는 계측이 아니다.
- 아래 수치는 계측기 규격·실제 부품 데이터에 근거한 허용 범위가 아니라 연구자가 고정한
  스트레스 격자다. 실측 정확도, 특정 온도, 실제 환경 확률로 환산하지 않는다.
- 단독 축은 나머지 오차를 0으로 둔다. 결과를 본 뒤 제외·문턱 변경·격자 추가를 하지 않는다.

105개 시나리오 × (고장 6개 + 대조군 3개) = **945개 역추정**이다.
고장 630건·대조군 315건을 분리하며, 합산 진단 정답률을 만들지 않는다.
잡음 seed는 SHA256(robustness_v1|design_id|draw)의 앞 16자리 정수다.
같은 설계·draw의 27개 표준정규 표본을 잡음 수준·고장·대조군 사이에 공유해 비교한다.
따라서 반복 행을 서로 독립인 실제 회로나 실험으로 해석하지 않는다.
공통 dB offset은 수동성에 맞춰 clipping하지 않으며 계측 오차의 관측값으로 취급한다.

## 지표와 검증

고장: 위치와 방향 모두 정답 / 특정했지만 오진 / 판단 보류의 합이 분모다.
대조군: 단일 부품 오경보 / 판단 보류의 합이 분모다. 무고장 보류를 고장 진단 정답에 합산하지 않는다.
최상위 가설의 정답 여부도 별도로 기록해 순위 실패와 문턱에 의한 보류를 구분한다.
모든 가설의 잔차를 저장하고, 결과에서 평가 격자상의 첫 실패를 기술할 수 있지만
격자 사이의 경계·단조성·실제 운용 허용치를 추정하지 않는다.

모든 입력·결과를 보존한다. 기존 6고장의 무오차 fit 및 spectrum을 이전 기록과 대조한다.
모든 역추정을 재실행하고 각 가설 RMSE와 진단 문턱·집계를 독립 계산한다.
물리적 과거 netlist와 실제 sweep의 고유 조합은 모두 native SPICE로 실행하고
2001점 ABCD, 9점 nodal 및 반올림·잡음 입력을 검사한다. 복구 성능은 이번에 평가하지 않는다.
코드·입력·이 계획을 hash로 고정한 후 실행한다. 오류는 숨기거나 성공으로 간주하지 않는다.
