# 확장 실험 실행 기록

**완료 안내:** 아래 내용은 시작 당시의 중간 기록이다. 이후 72개 경로 모두 완료했으며,
최종 복구는 무피드백 33/36, 피드백 31/36이다. 응답 97개와 후보 재시뮬레이션
96개를 검증했다. 최신 결론은 [최종 결과](budget_transfer_v4_results.md)를 따른다.

2026-09-06: 공식 양식 원고 보완 및 평가기 수정 후, 사용자가 기존 OpenAI API 키
재사용을 승인하여 실제 v4 실험을 시작했다. 이 문서는 **첫 사례 완료 시점의 중간 기록**이며,
전체 결과 보고서가 아니다. 최신 완료 집계는 `build/experiments/budget_transfer_v4/summary.json`이다.

## 실행 범위와 확인

4개 새 설계 파라미터, 12개 합성 값 고장, 3회 반복, feedback/no-feedback 두 조건의
총 72개 경로를 고정했다. 조건별 최대 3회, 전체 API 호출 상한은 216회다.
12개 모두 정상 PASS·고장 FAIL·정답 수정 PASS의 사전 검사를 통과했다.
원고·개인정보·기존 설계 파일은 API 입력에 포함하지 않는다. 회로 수식으로 생성한
합성 netlist, 목표 수치, 계산된 simulation metrics와 해당 실행의 이전 시도만 전달한다.

첫 6회 제한 배치 후 저장·재개를 확인하고 같은 프로토콜로 나머지 실행을 시작했다.
프로토콜이나 출력 예산은 중간에 변경하지 않았다. 처음 6개 응답은 ID 중복과 원문
hash 이상이 없고, 수용된 후보 5개를 새로 시뮬레이션해 저장 metric·판정과 일치했다.
이후의 오프라인 감사는 다음 명령으로 현재까지 완료된 iteration을 검사한다.

```bash
.venv/bin/python scripts/audit_budget_transfer.py
```

## 첫 사례의 잠정 결과

대상은 `transfer_d1_f1` 하나다. 독립적인 회로 6개를 뜻하지 않는다.

| 조건 | 완료 경로 | 첫 시도 복구 | 최종 복구 | API 호출 | 후보 simulation | API/schema 실패 |
|---|---:|---:|---:|---:|---:|---:|
| no-feedback | 3 | 2 | 2 | 3 | 2 | 1 |
| feedback | 3 | 2 | 3 | 4 | 4 | 0 |

피드백 조건의 세 번째 반복은 첫 수정에서 specification을 충족하지 못했지만
실패 metric을 제공받은 두 번째 수정에서 PASS였다. 반면 no-feedback의 한 실행은
`incomplete`, 출력 2,000토큰 중 reasoning 2,000토큰, 가시 출력 없음으로 종료됐다.
이 한 건은 성능 분모에서 제외하지 않았다. 따라서 조건 간 1건 차이를 피드백의
인과적 효과로 해석하지 않는다. 최초 요청의 입력은 두 조건에서 동일하다.

첫 7회 usage에 따른 추정 비용은 약 $0.01255이며 실제 청구 금액은 아니다.
응답 미완료가 늘어나면 운영 실패 비중을 별도로 보고한다. 출력 상한에는 추론 토큰도
포함되며 가시 출력 없이 상한에 도달할 수 있다는 동작은
[OpenAI reasoning 문서](https://developers.openai.com/api/docs/guides/reasoning)와 일치한다.
응답 예산을 변경한 후속 실험은 별도 버전으로 분리해야 한다.

후속 확인: `transfer_d1_f2`의 feedback 첫 반복은 세 번 모두 specification을
충족하지 못했다. 초기 성공 사례만으로 확대 해석할 수 없음을 보여주며 이 실패도
그대로 보존했다. 누적 완료 응답 10개와 후보 재시뮬레이션 9개를 감사한 결과
원문·수정 회로·metric·판정의 불일치는 없었다. 나머지 실행은 진행 중이다.

## 해석과 다음 검토

전체 72개 경로가 끝나기 전에는 조건 간 우열이나 일반화 성능을 주장하지 않는다.
완료 후에는 사례별 복구, 최초/최종 복구, 진단과 보상 복구, 실패 종류, 토큰·시간·호출
비용을 분리 집계하고 저장 회로를 재검증한다. 12개 고장은 4개 설계에 묶여 있으며
새 topology나 실측 검증이 아니다. 새 결과는 기존 논문 수치에 아직 반영하지 않았다.

원시 요청·응답·회로·simulation 결과는 `build/experiments/budget_transfer_v4/`에
보관된다. `build/`는 기존 Git ignore 대상이므로 최종 재현 패키지에는 별도 보존이 필요하다.
