# 다중 보류 기준 보정·미사용 설계 평가와 적용

**미사용 설계의 확정 정답이 기존 487/2304에서 615/2304로 늘었다.** 새 기준의 관찰 오진은 0건, 무주입 대조군 오경보는 0/64였다. 사전 적용 조건을 통과해 새 진단 명령의 기본 정책으로 연결했다.

2026-09-06. API 0회. 개발 4설계, 별도 보정 4설계, 미사용 평가 4설계를 분리했다. 보정·평가는 각각 2,368행(주입 변화 2,304 + 무주입 대조 64)이다. 최종 평가 전에 정책을 고정했고 결과를 본 뒤 문턱을 다시 조정하지 않았다. 같은 수동 BPF 구조의 합성 주입 변화 진단이며 실측 성능·수리 성공률·인구집단 오진 확률 보증은 아니다.

## 적용한 기준

E0는 현재값을 과거에도 쓴 무변화 가설의 RMSE, E1/E2는 최선/차선 부품 가설 RMSE다. 다음 조건을 모두 만족할 때만 부품과 방향을 확정한다.

| 항목 | 보정 후 고정 기준 | 역할 |
|---|---|---|
| 측정 적합성 | E1 ≤ 0.02 dB | 큰 모델·측정 오차를 허용해 오진이 통과하는 것을 억제 |
| 후보 간격 | E2−E1 ≥ 0.03 dB | 서로 비슷한 부품 가설을 보류 |
| 후보 비율 | E2/max(E1, 0.01) ≥ 3 | 오차 크기에 비해 구분이 약한 후보를 보류 |
| 무고장 대조 | (E0−E1)/max(E1, 0.01) ≥ 8.054607 | 보정 대조군보다 강한 변화 증거를 요구 |
| 재검사 안정성 | 각 측정에 ±0.01 dB를 더한 4회 재최적화에서 부품·방향 4/4 일치 | 작은 입력 변화로 후보가 바뀌면 보류 |

0.01 dB는 분모가 너무 작아지지 않도록 둔 고정 바닥값이며 실측 분산 추정치가 아니다. 무고장 대조 점수는 환경 변화까지 최적으로 적합한 물리적 무고장 모형이 아니라, 여러 합성 nuisance가 있는 대조군의 경험적 점수 범위를 사용한다. 안정성 4/4도 확률적 신뢰도가 아니다.

## 숫자를 정한 방법

개발 자료에서 기준 형태를 정하고 36개 후보 격자를 사전 고정했다. τfit={0.01,0.015,0.02}, τgap={0.015,0.03,0.05,0.08}, τratio={3,5,10}이다. 보정 무주입 대조군 64건의 최대 T=7.322370에 10% 여유를 더해 τnull=8.054607로 정했다. 10%는 사전 설정한 경험적 여유이며 통계적 보증이 아니다.

보정에서 관찰 오진 0·오경보 0인 후보 중 확정 정답 584건을 얻는 설정을 골랐다. 동률이면 더 작은 τfit, 더 큰 τgap, 더 큰 τratio 순으로 선택했다. 후보·대조 점수·결과와 정책 파일을 고정한 후에만 holdout을 실행하도록 코드에서 순서를 제한했다. [사전 계획](abstention_calibration_v1_protocol.md).

판단을 내리는 비율과 그 판단의 오류를 함께 보는 설계는 선택적 예측의 risk–coverage 관점과 연결된다. [Geifman & El-Yaniv, 2017](https://arxiv.org/abs/1705.08500). 이번 구현은 그 논문의 확률적 보증 알고리즘을 적용한 것이 아니며, 설계 군집 4개만으로 낮은 모집단 오류율을 보장하지 않는다.

확정 정답의 증가는 주로 반올림만 있거나 작은 잡음이 있는 조건에서 나타났다. 큰 환경 변화·모델 불일치의 진단을 해결한 것은 아니다. 해당 조건을 계속 보류하면서 구분 가능한 작은 변화의 보류를 줄인 결과다.

## 평가 집합과 계산 비용

| 분할 | 설계 주파수 MHz | 기존 정답 | 새 정답 | 주입 변화 분모 | 대조군 분모 |
|---|---|---:|---:|---:|---:|
| 보정 | 133/179/227/283 | 451 | 584 | 2304 | 64 |
| 미사용 평가 | 147/193/251/307 | 487 | 615 | 2304 | 64 |

각 분할은 6개 주 부품×±1/3/10%와 무주입 상태를 대상으로 같은 16개 프로파일을 썼다. 같은 설계·draw의 오차 벡터가 여러 행에 공유되므로 반복 행을 독립 회로 표본으로 보지 않는다. 기준 회로 및 주입 후 성능 규격으로 제외하지 않는 진단 프로토콜을 유지했다.

- 보정: 기준 회로 PASS 4/4, 주입 144상태 중 규격 PASS 81·FAIL 63. 규격 판정으로 주입 상태를 제외하지 않았다.
- 미사용 평가: 기준 회로 PASS 4/4, 주입 144상태 중 규격 PASS 88·FAIL 56. 규격 판정으로 주입 상태를 제외하지 않았다.
- 보정: 원본 fit 2,368회 + 안정성 fit 2,336회, fit 전방 계산 1,891,008회 + E0 계산 2,368회.
- 미사용 평가: 원본 fit 2,368회 + 안정성 fit 2,484회, fit 전방 계산 1,950,504회 + E0 계산 2,368회.

기존 판정은 원본 fit에서 얻고, 새 기준은 추가 재최적화를 사용한다. 따라서 동일 계산 예산 비교가 아니다. 어떤 후보도 통과할 수 없는 입력은 재검사를 생략하므로 STABILITY_NOT_CONFIRMED는 실제 흔들림과 재검사 미실행을 모두 포함한다.

미사용 평가에서 재검사를 수행한 621건은 621건 모두 4/4 후보가 일치했다. 고정된 점수에서 적합성·간격·비율만 적용한 판정과 전체 판정의 차이도 0건이었다. 따라서 이번 개선은 후보 구분 기준 변경에서 관찰됐으며, 무고장 대조와 안정성 조건의 추가 이점은 이 평가로 입증하지 못했다. 해당 조건을 일반적으로 불필요하다고 결론내리지는 않는다.

## 적용 및 재현

적용 상태: **ACTIVE_SYNTHETIC_VALIDATED**. 기존 실험 스크립트는 동결된 기준을 유지한다. 새 진단 명령은 원시 입력에서 fit·점수·재검사를 다시 계산하고, 정책 또는 입력을 읽거나 검증할 수 없으면 unknown으로 보류한다.

```bash
.venv/bin/python scripts/diagnose_reference.py --input input.json --output diagnosis.json
```

입력은 `source`, `public`, `reference` 세 필드를 가진 JSON 또는 실험 기록의 `estimator_input`이다. 현재 주 값과 공용 등가모형이 주어진 기존 합성 회로 입력 계약을 사용한다. active 설정은 `configs/diagnosis_abstention.json`, 고정 정책은 `experiments/diagnosis_abstention_v1.json`이다. LLM 호출이나 회로 수정·수리 승인은 하지 않는다.

```bash
.venv/bin/python scripts/audit_abstention_calibration.py
.venv/bin/python scripts/activate_abstention_policy.py
.venv/bin/python scripts/report_abstention_calibration.py
```
